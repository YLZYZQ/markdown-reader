# v1.4 开发计划

制定日期：2026-08-30。范围来自 [optimization-roadmap.md](optimization-roadmap.md) P1 四项：
**① 自动保存 + 崩溃恢复 ② 最近打开 ③ 代码块复制按钮 ④ 字体/字号设置**。
目标版本：v1.4.0。

范围裁剪（记录决策）：最近打开的"开始页展示"不做（菜单入口已够用）；行高设置不做（字号/字体已覆盖实际需求）。

---

## ① 自动保存 + 崩溃恢复

- **自动保存**（默认关，视图菜单勾选项）：开启后内容修改 2 秒防抖静默保存（仅对已保存过路径的文档生效，未命名文档跳过）；保存成功仅更新状态栏不弹 toast；`saveFile` 加防重入锁。
- **崩溃恢复**（与自动保存无关，始终开启）：内容变更 1 秒防抖写入 `userData/backup/session.json`（`{ filePath, baseUrl, content, savedAt }`，原子写）；保存成功/新建文档/干净关闭时清除。启动时若存在备份 → 主进程对话框「恢复上次未保存的内容？/ 恢复 / 放弃」→ 恢复则载入内容并置为未保存态（Ctrl+S 直接保存）。
- 新模块 `lib/session-backup.js`（原子读写/清除，损坏回落 null，可单测）。

## ② 最近打开

- `lib/recent.js`：`addRecentEntry` 按路径小写去重、置顶、上限 10 条；`loadRecent` 容错读取。
- 记录时机：文档打开成功、保存成功（含另存为）。存 `userData/recent.json`。
- 入口：文件菜单「最近打开」子菜单（最多 10 项，显示文件名，点击经既有授权链路打开）+「清除最近打开记录」；菜单实时重建。

## ③ 代码块复制按钮

- 悬浮于代码块右上角的「复制」按钮（点击后短暂变「已复制」），覆盖源码预览与所见即所得两种模式；Mermaid 图表块排除。
- MutationObserver 防抖补挂（预览频繁重渲染，只补缺失按钮）；复制走 `navigator.clipboard.writeText`，失败回落 `execCommand('copy')`。

## ④ 字体/字号设置

- 偏好新增：`autoSave`(bool)、`editorFontSize`(12-28，默认 16)、`editorFontFamily`(''|'sans'|'serif'|'mono'，默认 '' 跟随主题)。
- 视图菜单：「自动保存」勾选项、「字号」子菜单（14/16/18/20/22/24）、「正文字体」子菜单（跟随主题/无衬线/衬线/等宽），勾选态实时重建。
- 应用：CSS 变量 `--md-reader-font-size` / `--md-reader-font-family` 作用于源码编辑器、所见即所得编辑区与预览。

## 验收标准

- [ ] 开启自动保存 → 修改已保存文档 → 2 秒内自动落盘且状态栏提示，不弹 toast；
- [ ] 未命名文档修改不触发自动保存对话框；
- [ ] 修改未保存 → 结束进程 → 重新启动提示恢复 → 恢复后内容完整且为未保存态；
- [ ] 保存成功/新建/干净关闭后备份清除；
- [ ] 打开 3 个文档 → 最近打开按最新排序且无重复；超过 10 条裁剪；清除记录后菜单显示空；
- [ ] 代码块出现复制按钮，点击后剪贴板内容与代码一致，Mermaid 块无按钮；
- [ ] 字号/字体切换即时生效并跨重启保持；非法偏好值回落默认；
- [ ] 单测：session-backup ≥6 例、recent ≥6 例、preferences 扩展 ≥3 例；冒烟新增自动保存接线、备份写入、字号变量、复制按钮断言。
